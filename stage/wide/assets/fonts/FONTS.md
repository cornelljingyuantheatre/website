# Prototype fonts

- `noto-serif-sc-600-intro.woff2` — Noto Serif SC SemiBold (Figma `192:160`), subset to the 54 introduction characters. SIL Open Font License 1.1; source npm `@fontsource/noto-serif-sc@5.3.1`.
- `inter-latin-600.woff2` — Inter SemiBold for the Tickets / Explore buttons (Figma `196:421`, `196:422`). SIL Open Font License 1.1; source npm `@fontsource/inter@5.3.0`.
- The title uses the existing `../../assets/fonts/aaruiyati-title.woff2` (see that folder's FONTS.md).
- The date uses the system UI face, because Figma's SF Pro is licensed for Apple platforms only.
